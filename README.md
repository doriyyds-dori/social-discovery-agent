# Social Discovery Agent

> 一款面向内容运营团队的**本地内容发现与任务管理工具**，帮助团队高效筛选有价值的社交媒体内容，并对接跟进任务。

---

## 项目目标

帮助内容运营团队：
- 记录和管理社交媒体内容线索（抖音、小红书、视频号、微博等）
- 对内容进行评估分级（内容价值、评论价值、推荐动作）
- 识别评论中的关键用户信号（试驾咨询、价格咨询等）
- 快速创建关联内容的跟进任务，并自动生成任务编号

---

## 当前已实现功能

| 功能模块 | 说明 |
|------|------|
| 关键词管理 | 添加、查看关键词，用于内容发现参考 |
| 内容管理 | 添加内容记录，含平台、URL、备注、评估字段 |
| 内容评估 | 内联编辑内容价值等级、评论价值等级、推荐动作、评论关键信号 |
| 内容筛选 | 按平台、评论价值、评论关键信号、推荐动作筛选内容列表 |
| 内容排序 | 默认按推荐动作 > 评论价值 > 创建时间排序 |
| 任务创建 | 任务自动关联内容，填写负责人、截止时间、任务说明 |
| 一键创建任务 | 在内容页直接对某条内容一键创建关联任务 |
| 任务编号 | 格式：`RW-平台码-YYYYMMDD-序号`（如 `RW-XHS-20260320-001`） |
| 任务状态管理 | 支持：待处理 / 处理中 / 已完成 / 已跳过 |
| 完成时间记录 | 状态改为已完成时自动写入完成时间 |
| 自动数据库迁移 | 后端启动时自动为现有数据库添加新字段，无需删库 |

## 本地启动步骤

### 前提条件
- Python 3.10+
- 安装依赖：`pip install -r requirements.txt`

### 启动后端

```bash
python -m uvicorn backend.main:app --reload
```

后端运行在：http://localhost:8000

### 启动前端

```bash
python -m streamlit run frontend/app.py
```

前端运行在：http://localhost:8501

> **注意**：请先启动后端，再启动前端。

## 当前测试通过的核心流程

1. **内容入库流程**：添加内容 → 填写平台/URL/备注 → 设置评估字段（内容价值/评论价值/推荐动作/评论关键信号）
2. **内容筛选流程**：按平台、评论价值等条件组合筛选 → 列表实时更新
3. **一键创建任务流程**：在内容页展开内容 → 填写负责人等信息 → 创建任务 → 任务编号自动生成
4. **任务跟进流程**：在任务页更新状态 → 改为已完成时自动记录完成时间

## 当前已知限制

- 无用户认证，适合本地或受信任内网使用
- 无内容自动抓取功能（需手动填写内容记录）
- 无评论自动分析功能（评论关键信号需人工选择）
- 无多用户协作支持
- 数据库为本地 SQLite，不支持多机共享
- 任务编号序号基于当天前缀的数量，不支持跨平台唯一性保证（相同日期相同平台保证唯一）

## 下一阶段建议方向

1. **内容自动发现** — 接入平台 API 或爬虫，自动获取内容线索
2. **评论价值二层筛选** — 在评论关键信号基础上增加意向评分维度
3. **任务批量分派** — 支持批量选中内容，一次性创建多个任务
4. **数据导出** — 支持将内容/任务列表导出为 Excel 或 CSV
5. **通知集成** — 任务状态变更时发送飞书/企业微信通知
